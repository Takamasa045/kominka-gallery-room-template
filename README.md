# みんなの古民家ギャラリー｜お部屋のひな形

AI に話しかけて `room-recipe.json` を編集 → GitHub にコミット＆プッシュするだけ！
プライベート（非公開）でも OK！「GitHubとつなぐ」でお部屋フォルダを 1 つ選んでおけば、自動で最新のお部屋が反映されます。

---

## かんたん 3 ステップ

1. **自分の GitHub にコピー（最初の 1 回だけ）**
   右上の **「Use this template」→「Create a new repository」** を押して作成します（**Private（非公開）でも Public（公開）でも OK**）。
2. **「GitHubとつなぐ」でお部屋フォルダを 1 つ選ぶ**
   会員サイトの **「お部屋を編集」→「GitHub連携」** タブで **「GitHubとつなぐ」** を押し、作ったお部屋フォルダを 1 つ選びます（見るだけ専用・書き換え不可・いつでも解除 OK）。もちろん公開フォルダのまま URL を貼る使い方もできます。
3. **AI 相棒に頼んでコミット＆プッシュ！**
   Antigravity / Codex / Claude Code でこのフォルダを開き、日本語で頼むだけ。
   部屋を開いたとき（または **「GitHub更新」** ボタン 1 押し）に自動で最新が反映されます。

> ⚠️ **大事なルール**
> 重い画像・動画、大切な写真、個人情報や秘密情報は **GitHub に置かないでください**。
> 写真（5MBまで）・短い動画（15MBまで）はギャラリー画面のアップロード、長い動画は YouTube リンクを使い、GitHub にはお部屋の設計図（`room-recipe.json` や特注 `index.html`）だけを置きます。

## 選べるバリエーション早見表

- **雰囲気色（9色）**：曙染（`daybreak`）／若苔（`moss`）／青磁鼠（`wind`）／藍鼠（`rain`）／琥珀染（`dusk`）／白群（`cloud`）／浅葱（`lake`）／本藍（`indigo`）／宵藍（`moon`）
- **正面の飾り方（6種）**：額装（`frame`）／吊り下げ（`hanging`）／衝立（`folding`）／床の間（`alcove`）／横長額（`panorama`）／重ね額（`layered`）
- **ノートの台（3種）**：ガラスケース（`case`）／書見台（`lectern`）／展示台（`table`）
- **動く作品の見せ方（3種）**：画面（`screen`）／投影（`projection`）／埋め込み（`recess`）
- **初期の照明**：昼の陽だまり（`false`）／夜の行灯（`true`）
- **公開設定**：下書き（`draft`）／みんなに公開（`published`）
