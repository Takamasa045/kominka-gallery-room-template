# みんなの古民家ギャラリー｜AIと一緒に育てるGitHubお部屋ひな形

このひな形は、会員サイトの **「みんなの古民家ギャラリー」** にあるあなた専用のお部屋を、**Antigravity / Codex / Claude Code** などのAI相棒に日本語で頼みながら、楽しく模様替え＆公開＆GitHub保存できるようにしたスターターキットです。

難しい記号を手で書き換える必要はありません。このフォルダには **AI相棒への説明書（`AGENTS.md` と `CLAUDE.md`）** と **一発アップロード＆公開スクリプト（`scripts/publish-to-gallery.mjs`）** が最初から入っているので、開いて日本語で話しかけるだけで使えます。

---

## はじめの3ステップ

### ステップ1：GitHubで「自分のお部屋置き場」を作る（最初の1回だけ）
1. このページの上にある緑色の **「Use this template（このひな形を使う）」** → **「Create a new repository」** を押します。
2. 自分のお部屋置き場の名前をつけます（例：`my-kominka-room`）。
3. 公開範囲は **「Private（非公開）」** を選びます。
   - ※非公開にしておくと、自分だけの鍵つき引き出しになるので、途中のメモを誰にも見られず安心です。
4. **「Create repository」** を押して、自分のお部屋置き場ができあがり！
5. できあがった自分のページURLを、普段使っている **Antigravity / Codex / Claude Code** に「このGitHubのお部屋置き場をパソコンに持ってきて開いて」と頼むか、手元のフォルダへ取り込みます。

### ステップ2（おすすめ）：AI相棒専用の鍵を1回だけ設定する
画像や短い動画をAI相棒に渡して **「これを自分の展示室に飾って公開して！」** と頼むだけで一発完了させたいときは、最初の1回だけ鍵を設定します。

1. 会員サイトの **「みんなの古民家ギャラリー」** → **「お部屋を編集」** → **「GitHubで管理・練習」** タブを開きます。
2. **「AI相棒用の鍵を発行する」** を押し、出てきた **「AI相棒に貼る初期設定メッセージをコピー」** を押します。
3. このフォルダを開いている Antigravity / Codex / Claude Code にそのまま貼り付けて送信します。
   - AI相棒がこのパソコンの `.env.local` にだけ保存してくれます（`.gitignore` で除外されているため GitHub へは絶対に送られません）。
   - 「準備できたよ！」と返ってきたら完了です！

> **大切なルール**：`.env.local`（`mgk_` で始まる鍵）や、重い画像・動画ファイル本体は **絶対に GitHub へ保存・公開しません**。画像や短い動画は AI相棒が `scripts/publish-to-gallery.mjs` を使って本番の会員専用保管庫へ直接アップしてくれます。

### ステップ3：AI相棒に日本語で頼んで飾る・公開する・GitHubへ記録する
1. 自分のパソコンのお部屋フォルダを **Antigravity / Codex / Claude Code** で開きます。
2. あとは普段どおりの日本語で頼むだけ！
   - **画像や動画を渡して一発公開**：「この画像を正面の作品として飾って公開して！」「この短い動画を動く作品にして公開して！」
   - **模様替え＆GitHub保存**：「夜の行灯にして、雰囲気色を宵藍（moon）に変えて、GitHubに保存して」
   - **開発中GitHubを紹介棚に追加**：「いま作っているこのGitHubリポジトリを開発中プロジェクトに追加して公開して！」
3. ※鍵を設定していない場合でも、できあがった `room-recipe.json` を会員サイトの **「お部屋を編集」→「GitHubで管理・練習」** タブからファイル選択または貼り付けで読み込んで「お部屋を保存する」を押せば反映できます。

## そのまま使える！AI相棒への頼み方フレーズ集

Antigravity / Codex / Claude Code のチャット欄へ、そのままコピーして話しかけてみてください。

1. **画像を添付して飾って一発公開する（おすすめ！）**
   > この画像を自分の展示室にアップロードして、正面の作品としてタイトルとやさしい説明をつけて飾って公開して！
2. **短い動画を添付して飾って一発公開する**
   > この短い動画（15MB以内のMP4/WebM）を自分の展示室にアップロードして、動く作品として飾って公開して！
3. **YouTube 動画を作品として飾る**
   > このYouTube動画（https://youtu.be/...）を「動きの習作」として飾って公開して！
4. **開発中GitHubを紹介棚に追加する（最大5件）**
   > いま開発中のこのGitHubリポジトリ（https://github.com/...）を、自分の展示室の「開発中プロジェクト」に追加して公開して！
5. **部屋の名前と自分の名前を変える**
   > 部屋の名前を「安曇野ひだまり室」、作者名を「さくら」に変えて、ひとこともあたたかい挨拶にして。
6. **夜の行灯＆雰囲気色を変える**
   > このフォルダの room-recipe.json を夜の行灯にして、雰囲気色を宵藍（moon）に変えて、GitHubに保存して。
7. **正面の飾り方とノートの台を変える**
   > 正面の作品を床の間（alcove）の飾り方にして、ノートの台をガラスケースにして。
8. **観察ノート3ページをまとめて整える**
   > 観察ノートの3ページを、今の部屋テーマに合うやわらかな文章に書き換えて。
9. **これまでの記録を見て、1つ前の状態に戻す**
   > これまでの変更履歴をわかりやすく見せて。気に入らなければ1つ前の状態へ戻したい。
10. **いまの展示室の状態を確認する**
    > いま本番の自分の展示室がどうなっているか確認して教えて。

## AIに頼めるお部屋のバリエーション早見表

日本語の名前でそのままAIに頼めます（「若苔にして」「衝立にして」など）。

- **お部屋の雰囲気色（9色）**：
  - 曙染（`daybreak`）／ 若苔（`moss`）／ 青磁鼠（`wind`）／ 藍鼠（`rain`）／ 琥珀染（`dusk`）／ 白群（`cloud`）／ 浅葱（`lake`）／ 本藍（`indigo`）／ 宵藍（`moon`）
- **正面作品の飾り方（6種類）**：
  - 額装（`frame`）／ 吊り下げ（`hanging`）／ 衝立（`folding`）／ 床の間（`alcove`）／ 横長額（`panorama`）／ 重ね額（`layered`）
- **ノートの台（3種類）**：
  - ガラスケース（`case`）／ 書見台（`lectern`）／ 展示台（`table`）
- **動く作品の見せ方（3種類）**：
  - 画面（`screen`）／ 投影（`projection`）／ 埋め込み（`recess`）
- **最初の照明（2種類）**：
  - 昼の陽だまり（`false`）／ 夜の行灯（`true`）
- **作品（`works`｜0〜8点）**：
  - 絵・版画（`print`）／ 観察ノート（`note`）／ 動きの習作（`motion`）
  - **画像（`imageUrl`）**：PNG / JPEG / WebP / GIF（5MB以内）を会員専用保管庫へ直接アップしたパス（`/api/gallery/media/...`）、または `https://` から始まる安全なURL。画像なしでも和風モチーフで綺麗に展示されます。
  - **動画（`videoUrl`）**：短い動画 MP4 / WebM（15MB以内）を直接アップしたパス（`/api/gallery/media/...`）、または安全な YouTube リンク（`watch` / `youtu.be` / `shorts`）。
- **開発中GitHub紹介棚（`curation.projects`｜最大5件）**：
  - プロジェクト名・GitHub URL（`https://github.com/...`）・ひとこと説明・公開デモURL（任意）・状態4種類：構想中（`idea`）／ 開発中（`building`）／ お試し公開中（`beta`）／ 公開済み（`launched`）
- **公開設定（2種類）**：
  - 下書き・自分だけ（`draft`）／ みんなに公開（`published`）

## 直接公開スクリプトの使い方（参考）

普段はAI相棒が自動で呼び出してくれるので、手で打つ必要はありません。

```bash
# いまの自分の展示室の状態を確認
node scripts/publish-to-gallery.mjs status

# 画像または短い動画を本番の会員専用保管庫へアップロード
node scripts/publish-to-gallery.mjs upload ./my-art.png

# room-recipe.json の内容を本番の展示室へ反映・公開
node scripts/publish-to-gallery.mjs publish --recipe room-recipe.json --status published
```

## もしAIツールが手元にないとき・困ったときは

- **パソコンのAIツールがないとき**：GitHubの画面で `room-recipe.json` を開き、右上の鉛筆マークから1か所だけ書き換えて保存することもできます。
- **スマホ参加・途中で迷ったとき**：いつでも会員サイトの **「かんたんお部屋づくり」** や **「こだわりカスタマイズ」** タブから、ボタンだけで画像・動画のアップロードや編集・公開ができます。
- **うまく読み込めなくなったとき**：AI相棒に「さっきの元気な状態に戻して」と頼むか、会員サイトの「レシピをコピー」からきれいなレシピをいつでも作り直せます。
- **鍵を誤って見せてしまったとき**：会員サイトの「お部屋を編集」→「GitHubで管理・練習」タブから **「鍵を無効にする」** または **「鍵を作り直す」** を押せば、すぐに古い鍵を止められます。
